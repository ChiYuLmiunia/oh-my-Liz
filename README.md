# 🐭 鼠鼠发展改革委员会

一个可爱的虚拟币账户管理系统。

## 功能特点

- **三种账户角色**：主播、管理员、普通用户
- **开放注册**：用户注册后需要管理员审核
- **鼠鼠币系统**：用户可以获取、查看和消费鼠鼠币
- **商店系统**：支持虚拟权益、实体礼物、特权三种商品类型
- **可爱界面**：粉色系鼠鼠风格UI

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务器

```bash
npm start
```

访问 http://localhost:3000

## 默认账户

系统预置了两个账户：

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin123 | 管理员 |
| streamer | streamer123 | 主播 |

## 页面说明

- `/` - 登录/注册页
- `/home` - 用户主页（查看余额、购买记录）
- `/shop` - 鼠鼠商店（购买商品）
- `/purchases` - 购买历史
- `/admin` - 管理后台（需要主播/管理员权限）

## 角色权限

### 普通用户
- 注册账号（待审核）
- 查看余额
- 在商店购买商品
- 查看购买历史

### 主播
- 所有普通用户权限
- 查看所有用户信息
- 给用户添加/扣除鼠鼠币
- 上架/管理商品
- 查看待审核用户

### 管理员
- 所有主播权限
- 审核新用户账号
- 修改用户角色
- 不能修改系统管理员账户

## 商品类型

- 🎫 虚拟权益 - 虚拟物品或服务
- 🎁 实体礼物 - 实体物品
- ⭐ 特权 - 特殊权限或福利

## 技术栈

- **后端**: Node.js + Express 5.x
- **数据库**: SQLite (better-sqlite3)
- **认证**: JWT
- **前端**: HTML5 + CSS3 + Vanilla JavaScript
